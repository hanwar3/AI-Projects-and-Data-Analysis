Pakistan · 1900–2025

Earthquake origin versus earthquake impact

The Punjab plain has 61 catalogued epicentres against 840 in the Sulaiman–Kirthar belt at the same latitudes. Yet 98.4% of Pakistan has felt at least MMI IV since 2000, and 28.9% has felt MMI VI or more.

An epicentre map is the usual way to show seismic risk, and it understates exposure exactly where most people live. Lahore's strongest shaking came from a rupture 340 km away. The companion map shows shaking received, built by compositing the maximum intensity from every USGS ShakeMap grid since 2000.

Technical report (PDF, 11 pages) Third map: magnitude of the causative event Code
Data
USGS ComCat catalogue (12,715 earthquakes, M ≥ 2.5); USGS ShakeMap grids for 309 events; AWS Terrain Tiles elevation and bathymetry; UN OCHA boundaries
Methods
Gaussian kernel density, cell-wise maximum MMI composite, Gutenberg–Richter fit, catalogue completeness check
Tools
Python, NumPy, SciPy, DuckDB, Matplotlib, Pillow; custom oblique renderer

Texas · FEMA OpenFEMA, USGS, TerraClimate

Flood damage that was actually paid out

272,924 National Flood Insurance Program claims in Texas since 2000, totalling $16.0 billion.

The flood map shows realised damage, not modelled hazard. Claims follow people, property and insurance uptake, so the legend warns that uninsured rural floodplains can be blank and still flood. Harris County dwarfs every other cluster, so the density is log-stretched to keep secondary centres visible. The series reuses the Pakistan method, so the two places can be read side by side.

Code
Data
OpenFEMA FimaNfipClaims API (paged, building + contents paid); USGS ComCat, M ≥ 2.5; TerraClimate 2000–2021 normals at ~4 km; US Census TIGER/Line
Methods
Payout-weighted point density, log stretch, bivariate colour classification
Tools
Python, requests, NumPy, SciPy, xarray; oblique-relief-maps skill

Pakistan · 2010 and 2022

Two megafloods on one terrain model

The 2010 flood moved as a wave down the Indus from Khyber Pakhtunkhwa to Sindh. The 2022 flood was driven by rain falling directly on Sindh and eastern Balochistan, where water pooled for months between the Kirthar range and the river embankments. Draping both footprints on the same relief shows how much of the damage sits on the flat lower Indus plain.

This connects to my earlier work at WWF-Pakistan on nature-based flood solutions for the Recharge Pakistan programme.

Code
Data
UN OCHA 2010 union-council inundation; UNOSAT / NASA–NOAA VIIRS 2022 flood extent (375 m); Copernicus GLO-30 DEM; Natural Earth rivers and coastline; HDX boundaries
Methods
Vector rasterisation onto the DEM grid, elevation-weighted inundation layer, ocean masking
Tools
Python, rasterio, GeoPandas, SciPy, Pillow; QGIS project for inspection

Pakistan · 2000–2021

Where it is hot, wet, or both

A bivariate map with four named corners: cool and dry (the Karakoram and Chagai), hot and dry (Thar, the lower Indus, Balochistan), cool and wet (the northern mountain fringe), and hot and wet (the Punjab and Khyber Pakhtunkhwa monsoon belt). Rainfall is read on a log scale so the arid south still shows variation.

Code
Data
TerraClimate monthly grids (Abatzoglou et al. 2018), ~4 km, read from cloud storage with xarray
Methods
Climate normals, regridding to terrain, bivariate colour classification
Tools
Python, xarray, adlfs, NumPy; oblique-relief-maps skill

Agentic AI

Tools and agent skills

I build these by directing Claude Code agents: I define the problem, the sources and the tests, the agent writes and runs the code, and I review every result before it is kept. They run locally, need no paid AI calls to operate, and keep API keys out of the code.

RFP Monitor

Watches 17 public procurement sources for open RFPs, expressions of interest and calls for proposals in disaster risk reduction, resilience, climate adaptation and urban planning, and ranks them in one dashboard.

IUCN · IFRC · ADPC · CDEMA · UNDP · WWF-Pakistan
   → keyword match + transparent relevance score
   → SQLite (notice ID as primary key, no duplicates)
   → Streamlit dashboard + Excel export + per-source run log
  • Drives the local Edge or Chrome through Playwright for four sites that block scripts (Cloudflare, Drupal antibot, a 403 wall, a JavaScript-only list).

Python · FastAPI · SQLite · Apify

jobhunt

A local job search that pulls postings from federal, humanitarian, employer and aggregator sources, scores each one against a CV, and tracks applications. Built for a narrow field where precision matters more than volume.

Code and README 
Greenhouse · Lever · Ashby · Workable boards · USAJOBS · ReliefWeb
Adzuna · Remotive · Jobicy · Arbeitnow · LinkedIn and Indeed (Apify)
   → deduplicate across sources
   → 0–100 score (title, skills, domain, seniority, location) + eligibility flags
   → SQLite pipeline: saved, applied, follow-up dates
   → dashboard + CLI → application packet with matched CV bullets
  • Scoring is a weighted model, not an LLM call, so results are stable and jobhunt show prints the arithmetic.
  • Twelve built-in regions, from the DC metro to South Asia and the Gulf; one setting retargets the search.
  • Enforces a monthly spending cap on paid scrapers and logs the estimated cost of every run.
  • 18 automated tests.

oblique-relief-maps

A reusable skill that teaches Claude to produce the relief maps above and the report that documents them. I wrote it after the Pakistan earthquake work so the method would not have to be rediscovered; the Pakistan climate map and the whole Texas series were then each made from a short request.

Practice

How I work with AI

Start from the question

Before any code, I decide what the output must answer and for whom. That is how the epicentre map gained a shaking map beside it.

Use primary, open sources

USGS, FEMA, UN OCHA, TerraClimate and official procurement portals, pulled by API and cited on every figure.

Check what the agent produces

Counts are compared against the source, tests run on every change, and anything I cannot verify stays out of the final product.

Leave it reusable

READMEs, technical reports and agent skills, so the next analysis starts from what the last one learned.
